# Security and Configuration Incidents

Case studies focused on incident containment, credential revocation, audit forensics, and remediation of security misconfigurations.

## Focus Areas
- Exposed API tokens, private keys, and credential leakage
- Over-permissive IAM roles and service account privileges
- Unauthorized privilege escalation and lateral movement containment
- Configuration drift and unapproved security policy overrides
- Emergency credential rotation and session revocation
